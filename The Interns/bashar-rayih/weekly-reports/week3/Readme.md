## Challenges and Solutions
- **Challenge 1: Finding a UI**
  - *Problem:* Couldn't find a UI that i can perfectly replicate in MIT app inventor
  - *Solution:* Instead of wasting all my time on finding "the perfect" UI to replicate, i looked for one that i can get as close as i can get to replicate it.
- **Challenge 2: MIT functionality**
  - *Problem:* MIT does not allow the user drag and drop Texts, buttons, and images wherever they want
  - *Solution:* I used HorizontalArrangements, and VerticalArrangements, to fill blanks so I can place Texts, buttons, and images where I wanted them to be.
- **Challenge 3: no overlapping UI**
  - *Problem:* Can't place a text or a button on top of an image
  - *Solution:* I put the images i wanted as backgrounds for HorizontalArrangements, and VerticalArrangements and placed the texts and buttons inside the arrangements.
- **Challenge 4: Back button functionality**
  - *Problem:* Since you cant make 1 button do 2 functionalities i had an issue with the back button where i sometimes get stuck on a page or on the loading screens
  - *Solution:* I added a when any function to automatically close the screen I was on whenever I open a new screen. And I did the same for the loading screen timer so I won't get stuck on the loading screen
