### Task 2: Difference between API automation vs UI automation

* **API automation:** tests the backend directly: valid/invalid credentials, password rules, rate limiting, token expiry, error codes. These tests are fast, stable, and cheap, so you put the many detailed logic and edge-case checks there
* **UI automation:** checks that the real user journey works end to end: screens connect, buttons work, errors actually appear to the user. These tests are slow and break easily. Animations, timing, network, simulator state, and UI changes can all make them fail even when the app is fine.
