Tools Used: Thunkable

I created a simple note-taking application called Zen Note using Thunkable. The application is designed to allow users to create, view, and manage their notes in a simple and organized way. The main purpose of the application is to provide users with an easy-to-use interface for writing down and keeping track of their notes.

The main screen allows the user to easily access the different features of the application. Users can create new notes and manage their existing notes through the available buttons and interface elements. The application was designed to keep the process simple and user-friendly, allowing users to interact with their notes without unnecessary steps.

I also added the necessary screens and navigation to allow users to move between the different parts of the application. The navigation makes it easier for users to access their notes and return to the previous screen when needed. I tested the different buttons and screen connections to make sure the application worked properly and that users could move through the app easily.

The application was created using the visual programming blocks provided by Thunkable, so the main focus was on understanding the logic behind the application, connecting UI elements to their functions, and organizing the different parts of the app. Overall, the project helped me understand how to build a basic mobile application, work with visual programming blocks, handle user interactions, create and manage information, and create navigation between multiple screens.
