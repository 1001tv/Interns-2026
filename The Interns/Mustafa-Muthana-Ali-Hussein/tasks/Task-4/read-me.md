Tools Used: HTML, CSS, JavaScript (VS Code)

I created a simple authentication web application called Sign Up & Sign In using HTML, CSS, and JavaScript.
The application is designed to allow users to register a new account and log into an existing account in a simple and
organized way. The main purpose of the application is to provide users with an easy-to-use interface for creating credentials
and storing user data directly in the browser using localStorage.

The main screen allows the user to easily access the different features of the application. Users can enter their email and 
password to register a new account or sign in to an existing one using the available input fields and submit buttons. 
The application was designed to keep the process simple and user-friendly, allowing users to register or sign in without
unnecessary steps.

I also added the necessary JavaScript logic to handle user inputs and verify credentials. The scripts allow the application
to save new user information into local storage and check existing records when signing in. I tested the different submit 
buttons and storage logic to make sure the application worked properly, alerting users whether their account was created or 
found successfully.

The application was created using fundamental web development technologies, so the main focus was on understanding
front-end logic, manipulating JSON data, connecting UI elements to JavaScript functions, and styling form elements
with CSS. Overall, the project helped me understand how to build a basic web application, work with browser storage, 
handle user input and authentication logic, and structure modern layouts.
