Tools Used: MIT App Inventor

For this project, I created a Quote of the Day application using MIT App Inventor. The application is designed to display 
inspirational and meaningful quotes from different well-known people. Each quote is presented together with the name of the 
person who said it, a short description about them, and their picture displayed as the background of the application.

The main screen allows the user to easily view different quotes by pressing a button. Each time the button is pressed, 
the application changes the displayed quote and updates the corresponding person's name, description, and background image.
This makes the application interactive and allows the user to explore multiple quotes without having to leave the main screen.

I also added a full list page where users can view all of the available quotes in one place. The user can navigate between the 
main quote screen and the full list page using navigation buttons. A back button was also included to make it easy for the user
to return to the previous page.

The application was created using the visual programming blocks provided by MIT App Inventor, so the main focus was on
understanding the logic behind the application, organizing the different pieces of information, and creating a simple and
user-friendly interface. Overall, the project helped me understand how to build a basic mobile application, work with lists
and variables, handle button interactions, and create navigation between multiple screens.
