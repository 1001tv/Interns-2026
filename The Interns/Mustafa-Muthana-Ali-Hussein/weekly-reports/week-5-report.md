During Week 5, I began exploring the fundamentals of front-end web development by focusing on HTML, CSS, and JavaScript. 
I learned how these three core technologies interact to create functional and structured web applications. 
HTML served as the skeleton of my project, allowing me to build form layouts, input fields, and interactive buttons. 
Through CSS, I practiced styling these elements to create clean user interfaces, using properties like Flexbox to align 
content centrally on the page and adjusting margins, colors, and borders for a better visual experience.

Alongside design, I delved into JavaScript to add functional logic and dynamic responses to user input. I practiced 
retrieving data directly from form inputs using DOM manipulation and learned how to save and load user information using 
the browser's local storage. This involved working with JSON formatting to store structured arrays of data and writing loops
and conditional statements to check credentials. Overall, this week provided a practical introduction to connecting web 
structure, design, and programming logic to build a working client-side application.

Building on these foundational skills, I spent time understanding how user actions directly drive application state 
and interface updates. I learned how event handlers link user inputs—such as button clicks—to custom JavaScript functions
that execute immediately. By managing data with local storage, I discovered how web applications maintain state across page
reloads without relying on external servers or database management systems. Converting complex JavaScript objects into JSON
strings using serialization methods proved essential for storing information securely in the browser environment,
while parsing that data back into usable arrays allowed me to process and search through records efficiently using 
conditional logic and iteration loops.

In addition to basic scripting and data storage, I explored important design principles related to layout structure, 
alignment, and modern component styling. Positioning elements cleanly using CSS Flexbox helped me understand how properties
like justification, alignment, and viewport-based sizing work together to keep content centered and visually balanced on 
varying screen sizes. I also experimented with basic styling patterns for form elements, such as input padding, custom 
button backgrounds, border radiuses, and shadow effects to improve overall user interface design. Moving forward, I plan
to refine these concepts by practicing cleaner code architecture, improving user input validation, and learning how to 
build responsive multi-page layouts using modern web standards.
