# Week 7 — Task Brief

**Clean Code: Readable, Maintainable, Professional Code**
Intern: Nour AlSabtin | Baghdad, Iraq

## Objective

Learn how to write readable, maintainable, testable, and professional code.

## Main Activities

- Use meaningful names
- Reduce duplicated code
- Improve function and class responsibility
- Apply separation of concerns
- Simplify complex logic
- Follow formatting and coding conventions
- Refactor an existing implementation
- Perform a peer code review
- Document the changes and reasoning

## Deliverables

- Before-and-after code comparison
- Refactored implementation
- Code review comments
- Weekly report

## Expected Outcome

Interns can identify code-quality problems, refactor code safely, and explain their improvements.

## Chosen Implementation

Refactored the **Interactive CV Dashboard** from Week 5: split the single `.html` file into `index.html`, `styles.css`, and `script.js`; replaced 15+ repeated hex colors with CSS custom properties; gave every button handler its own named function instead of anonymous `onclick` assignments; and simplified the word-counter and background-cycler logic.

**Live preview (unchanged behavior):** [nourcv1.netlify.app](https://nourcv1.netlify.app/)
