# Task 02 — Android Development

## Overview

For this task, I chose a recipe application design from Dribbble and recreated it using Kodular.

The goal was to understand more about Android development by working on both the visual design of the application and the logic behind how the different screens and features connect.

I wish I had access to an Android device so I could test the application properly, but unfortunately I was not able to get access to one during the task.

I would like to state that i made it sweets only just to make it easier

## Features Implemented

1- Welcome, login, and sign-up screens
2- Home screen with recipe sections
3- Recipe details screen
4- Multiple recipes using one reusable details screen
5- Ingredient checkboxes
6- Navigation between screens
7- Favorites feature using TinyDB
8- Favorites screen that displays saved recipes
